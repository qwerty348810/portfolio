Контекст

Работаю параллельно в двух продуктовых командах одной группы компаний — Foodpicasso и Clever.by. По трудовой — Тестировщик программного обеспечения в ООО «Фудстор», на рынке роль соответствует QA / E2E-тестировщику. Помимо тестирования веду весь блок роста: автоматизацию рекламы, веб-аналитику и SEO.

QA / E2E-тестирование

  • Ручное и автоматизированное E2E-тестирование веб-приложений, панелей управления и мобильных приложений.
  • Автоматизация на Playwright (TypeScript), тестирование REST API, прогон в CI на GitHub Actions.
  • Тест-дизайн, тест-кейсы, чек-листы, баг-репорты; ведение дефектов в YouTrack.
  • Приёмочное тестирование новых фич: согласование к релизу или возврат на доработку с воспроизводимым описанием дефекта.
  • Предложения по доработкам функционала на основе наблюдений из тестов и пользовательских сценариев.

Автоматизация рекламных систем (Node.js, Python)

  • Построил пайплайн автогенерации контекстной рекламы: Node.js-сервис собирает данные новых заведений, заполненные менеджерами → нормализует их в Google Sheets как слой конфигурации → скрипты автоматически создают кампании, группы и объявления.
  • Google Ads — генерация через Google Ads Scripts с подхватом данных из Google Sheets; Яндекс Директ — аналогичный пайплайн через Yandex Direct API на Python.
  • Миграция рекламного аккаунта между платформами: автоматический перенос более 1000 кампаний, 2500 групп и 3000 объявлений из Google Ads в Яндекс Директ.

Ведение рекламы и аналитика

  • Ведение рекламных аккаунтов Google Ads и Яндекс Директ для Foodpicasso и Clever.by.
  • Управление Яндекс Бизнес-карточками компаний.
  • Отчётность по трафику и конверсиям в Яндекс Метрике: переходы, источники, поведение пользователей.

SEO и производительность

  • SEO-продвижение сайтов Foodpicasso и Clever.by.
  • Оптимизация показателей PageSpeed Insights и Core Web Vitals.
  • Технический аудит и работа с метриками скорости загрузки.

Нейросети в работе

Нейросети — ежедневный рабочий инструмент: генерация и ревью тест-кейсов, написание E2E-сценариев, разбор логов, кластеризация семантики для SEO. LLM встроены в рабочий процесс на уровне привычки, а не эксперимента.
